Architecture

How nomArmy's trust boundary works

Worker / Coordinator split

The coordinator orchestrates work, while a worker (nom) executes a task inside an isolated sandbox and writes a brief report. The worker never touches Git; only the coordinator can commit or merge.

Claim vs Evidence

Worker output is a claim. An implement worker's report is a four-line statement that the coordinator verifies against the repository state. The repository and environment are evidence.

Git diffs as evidence

After a job finishes, the coordinator reads the Git diff between the base commit and the new commit. The diff shows exactly what changed, and the coordinator uses the diff to validate the worker's claim.

Scout citations

Scouts are read-only workers that answer research questions a deterministic tool can't. Every claim carries a citation [path:line] that the coordinator resolves to the exact file and line in the committed code, ensuring the claim can be independently verified.
