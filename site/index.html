Every byte verified 🍪

Your coding assistant plans; sandboxed workers build; nothing counts until nomArmy has checked it

AI coding workers are confident. Their "done, all tests pass" is a claim, not evidence. nomArmy lets your coding assistant (Claude Code, Codex or Cursor), the General, hand work to workers called noms, then checks every change itself before anything is committed.

How every byte gets verified

A worker's report is a claim. The repository is the evidence.

  • The nom works in its own git worktree, in a Podman sandbox with no network and no host credentials.
  • nomArmy reads the real diff from git, not the nom's description of it.
  • It runs your verification profile itself, in a fresh sandbox.
  • It reverts the production change and reruns the tests: a test that still passes proves nothing, so the job goes to review.
  • It blocks on secrets, and flags tests made to pass and code nothing calls.
  • Only then does it commit, on the nom's own branch. It never merges into yours.

Quickstart

Have Git, Node 24.16+ and Podman, then:

npm install -g nomarmy@alpha
cd your-project
nomarmy setup

nomarmy setup is a playbook: it shows a checklist and runs the next step each time you say yes. See the README for the full walkthrough.

What it does

  • Independent verification - Every report is checked against the repository and your own tests
  • Checking without building - mode: verify runs your tests on any branch with no worker and no model tokens
  • Agents - Jobs run on an API key, your own ChatGPT or Muse Code subscription, or a local model
  • The army - Roles (devs, security analyst, data architect, PM, PO) on the agents you choose
  • /feature - A whole feature from plan through build, review and acceptance, handed back as a branch
  • Harnesses - Go, Rust, Python, Node and mixed repos, Playwright browser tests and fake services, all offline

What we actually measured

What you get is work you don't have to take on faith, not cheaper work. Delegating costs the General tokens too, for briefing and review: on small, already-diagnosed tickets we measured 4 to 8 times more of the General's tokens than fixing the bug directly. It pays off on bigger tickets, parallel work, and anywhere you'd otherwise trust an agent's say-so.
